PROJECT
1. Skripsi - Web Harmony - FTI ITERA
Membangun subsistem administrasi digital persuratan kampus menggunakan React (frontend), Laravel (backend), dan MySQL (database), dengan metodologi pengembangan Rational Unified Process (RUP) dan manajemen tugas Kanban. Sistem ini berhasil mempercepat proses persuratan kampus dari 7-10 hari kerja menjadi 2-5 hari kerja, serta lulus pengujian Black Box 100% dan UAT 88,57% (Sangat Baik).
Link: https://harmony.fti.itera.ac.id/

2. SIMAS (Sistem Manajemen Surat) - Kominfo Bandar Lampung
Merancang arsitektur multi-tenant menggunakan Laravel, Inertia.js, dan React.js untuk mendigitalisasi alur validasi persuratan dan otomatisasi rekapitulasi data terpusat antar-instansi pemerintahan, sehingga proses persuratan antar instansi menjadi lebih tertata dan efisien.
Link: https://simas.bandarlampungkota.go.id/

3. SIMAMANG (Sistem Informasi Manajemen Magang) - Kominfo Bandar Lampung
Mengembangkan portal web pendaftaran magang untuk Kominfo Bandar Lampung yang memfasilitasi pembuatan akun, unggah dokumen persyaratan, dan pelacakan status pendaftaran, sehingga proses pendaftaran magang menjadi online dan transparan bagi pendaftar.
Link: https://simamang.bandarlampungkota.go.id/

4. CashEye (Program DBS Foundation)
Mengembangkan aplikasi aksesibilitas menggunakan Machine Learning dan Computer Vision untuk mendeteksi nominal uang Rupiah dari gambar dengan output berupa feedback audio, guna memfasilitasi kemandirian transaksi penyandang tunanetra dan lansia.
Link: https://wahyuapriansyah1.github.io/protofolio-casheye/

5. Afenter_PCD (Deteksi Area Parkir Motor)
Membangun aplikasi Python dengan Streamlit dan OpenCV melalui 11 tahap pengolahan citra, meliputi remove background (rembg), resize, grayscale, threshold Otsu, morfologi (closing/opening), distance transform, penentuan ROI, deteksi kontur, pembagian slot parkir, hingga pengecekan occupancy tiap slot. Hasilnya adalah aplikasi yang dapat menganalisis ketersediaan slot parkir motor dari gambar dataset maupun foto yang diunggah pengguna.
Link: https://afenter.streamlit.app/ 

6. Klasifikasi Gambar Buah
Mengimplementasikan arsitektur Convolutional Neural Network (CNN) dengan TensorFlow, dilatih pada dataset citra 5 jenis buah (Apple, Banana, Grape, Mango, Strawberry), menghasilkan model klasifikasi gambar yang dapat mengenali jenis buah dari citra yang diberikan.
Link: https://github.com/Sakti-122140123/Klasifikasi-Gambar

7. Kyuubi-MML (Multimodal Music Emotion Recognition)
Mengklasifikasikan emosi musik ke dalam 5 klaster menggunakan strategi Late Fusion pada tiga modalitas berbeda: Audio (model PANN), Lirik (model DeBERTa), dan MIDI (BiGRU + SVM), dibangun dengan framework PyTorch, menghasilkan sistem pengenalan emosi musik yang menggabungkan tiga sumber data sekaligus.
Link: https://github.com/Sakti-122140123/Kyuubi-MML

8. Sistem Rekomendasi Buku
Merancang dan membandingkan dua pendekatan pada dataset Book-Crossing (1 juta+ baris data): Content-Based Filtering (TF-IDF pada judul dan penulis) dan Collaborative Filtering (Cosine Similarity antar user). Collaborative Filtering terbukti jauh lebih unggul dengan Precision@5 sebesar 0.42, dibanding Content-Based Filtering yang hanya 0.04.
Link: https://github.com/Sakti-122140123/Model-Sistem-Rekomendasi

9. Prediksi Biaya Asuransi Medis
Melakukan preprocessing (encoding, scaling) pada dataset biaya asuransi, lalu membangun dan membandingkan model Regresi Linier dan Decision Tree, dengan hyperparameter tuning via GridSearchCV pada model Regresi Linier. Regresi Linier mencapai MSE 33.596.915, lebih akurat dibanding Decision Tree yang memiliki MSE 40.153.988.
Link: https://github.com/Sakti-122140123/Predictive-Analytics

10. Clustering & Klasifikasi Demografi Regional
Menggunakan algoritma K-Means untuk mengelompokkan data pengeluaran daerah, dengan jumlah cluster yang dioptimasi menggunakan Silhouette Score. Hasil klaster tersebut kemudian dijadikan label untuk melatih model Random Forest dan Logistic Regression, menghasilkan pemetaan klaster pengeluaran daerah beserta model klasifikasi untuk memprediksi klaster dari data baru.
Link: https://github.com/Sakti-122140123/Belajar_Machine_Learning_Untuk_Pemula

11. Analisis Sentimen "Access by KAI"
Melakukan scraping ulasan aplikasi dari Google Play Store, membersihkan teks, lalu menerapkan ekstraksi fitur TF-IDF dan melatih tiga model: Logistic Regression, XGBoost, dan Naive Bayes. Model XGBoost memberikan performa klasifikasi sentimen terbaik dengan akurasi 97%.
Link: https://github.com/Sakti-122140123/Analisis-Sentimen

12. End-to-End ETL Pipeline
Mengekstrak data produk fashion dari web menggunakan BeautifulSoup (50 halaman), mentransformasi data, lalu memuatnya secara serentak ke tiga tujuan: CSV, Google Sheets API, dan PostgreSQL. Seluruh alur diuji secara ketat menggunakan Pytest dan test coverage, menghasilkan pipeline ETL otomatis dan teruji yang menyimpan data ke tiga destinasi sekaligus.
Link: https://github.com/Sakti-122140123/ETL-Pipeline

13. CI/CD Pipeline untuk Model ML
Membangun workflow otomatis di GitHub Actions untuk melatih model (dataset Wine) menggunakan MLflow untuk tracking eksperimen, lalu men-build dan mendeploy model sebagai image Docker yang di-push ke Docker Hub, menghasilkan pipeline MLOps otomatis dari training hingga deployment dengan image Docker yang tersedia publik.
Link: https://github.com/Sakti-122140123/Workflow-CI

14. Dashboard Analisis Penyewaan Sepeda
Mengolah dataset Bike Sharing Washington D.C (2011-2012) menggunakan Pandas, lalu membangun UI Streamlit dengan sidebar interaktif untuk memfilter rentang tanggal, kondisi cuaca, dan musim, kemudian memvisualisasikannya via Seaborn/Matplotlib. Hasilnya adalah web dashboard interaktif yang menyorot insight pola penyewaan sepeda dan telah berhasil di-deploy ke Streamlit Cloud.
Link: https://submission-sakti-codingcamp2025.streamlit.app/
